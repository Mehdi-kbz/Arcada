# Arcana

Live at https://arcana.khabex.com

## Workflow

1. Clone the repo and create a branch: `git checkout -b my-change`
2. Make changes, run the app locally (`python app.py`, listens on port 3000).
3. Push the branch and open a pull request.
4. Merging to `main` triggers an automatic production deploy via Coolify (about 1-2 minutes).

See `CLAUDE.md` for deployment details and rules.
